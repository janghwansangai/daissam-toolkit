01

빠른 메모

수업 중 떠오른 것을 바로

  • 메모를 여러 개 쓰고 제목으로 골라 씁니다
  • 같은 Google 계정이면 교실 · 집 컴퓨터에서 이어서
  • 자주 보는 메모는 📌 고정
02

폴더 북마크

자주 가는 곳을 한곳에

  • 지금 보는 페이지 추가 + 한 번이면 저장
  • ‘과학’ · ‘학급 운영’ 처럼 폴더로 정리
  • Chrome 기본 북마크와 섞이지 않습니다
03

캡처 · 녹화

보이는 그대로, 한 번에

  • 보이는 부분 · 전체 페이지(스크롤) · 선택 영역
  • 찍으면 바탕화면 캡처이미지 폴더 저장 + 복사
  • 화면 녹화 · 카메라 함께 녹화 · 글자 뽑기
04

발표 도구

작게 보이는 것을, 크게

  • 화면 확대 · 큰 포인터 · 집중 모드
  • 화면 조각을 떼어 붙여 두는 핀
  • 발표 도우미 앱을 함께 설치하면 쓸 수 있어요
05

수업 유틸리티

교실 도구를 사이드바 하나에

  • 스톱워치 · 타이머 · 수업 시보
  • 발표자 뽑기 · 팀 포인트 판 · 소음 측정기
  • 녹음기 · 웹캠 · 유튜브 뮤직 조종기
06

자동 백업

잃어버릴 걱정 없이

  • 문서 → 다있쌤 백업 폴더에 저절로 저장
  • 하루 1번 · 바뀐 뒤 · 직접 — 한 달 보관
  • 날짜를 골라 복구, 다시 깔아도 살릴 수 있어요

3분 시작하기

설치부터 첫 메모까지 네 단계면 됩니다.

1

설치

Chrome 웹 스토어에서 다있쌤을 찾아 Chrome에 추가를 누릅니다.

2

고정

주소창 오른쪽 퍼즐 🧩 → 다있쌤 옆 압정을 눌러 고정하고, 아이콘을 누르면 오른쪽에 사이드바가 열립니다.

3

시작

이름을 적고 PIN 없이 바로 쓰기 · 게스트를 누르면 끝. 함께 쓰는 컴퓨터라면 PIN(숫자 4~12자리)을 정하세요.

4

발표 도우미

화면 확대 · 핀 · 화면 전체 캡처 · 자동 백업은 발표 도우미 앱이 맡습니다. 첫 화면이나 발표 탭에서 받아 설치하세요(맥 · 윈도우).

처음 화면

혼자 쓰는 컴퓨터라면 PIN 없이 바로 쓰기, 여러 사람이 쓰는 교실 컴퓨터라면 PIN을 정하세요. 아래 칸에서 발표 도우미 앱도 바로 받을 수 있습니다.

💡 직접 설치(개발자 모드)도 됩니다 — 소개 사이트에서 확장 ZIP 을 받아 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드.

안심하고 쓰도록

만든 사람도 볼 수 없는 구조입니다.

서버가 없습니다

회원가입 · 로그인 · 사용 기록 수집이 없습니다. 어디로도 내 자료를 보내지 않습니다.

내 자료는 내 곳에

메모 · 북마크는 내 Chrome(과 내 Google 계정 동기화), 캡처 · 백업은 이 컴퓨터에만 남습니다.

날짜로 되돌리기

자동 백업이 한 달 동안 남아 있어, 실수로 지워도 날짜를 골라 되살릴 수 있습니다.

자주 묻는 질문

막히는 곳이 있으면 먼저 여기를 보세요.

정말 무료인가요?

네. 광고도, 회원가입도, 결제도 없습니다.

내 메모가 어딘가로 보내지나요?

아니요. 다있쌤에는 서버가 없습니다. 메모 · 북마크는 내 Chrome(과 내 Google 계정 동기화)에, 캡처와 백업은 내 컴퓨터에만 남습니다. 만든 사람도 볼 수 없습니다.

발표 도우미 앱은 꼭 깔아야 하나요?

메모 · 북마크 · 브라우저 캡처 · 타이머는 확장만으로 됩니다. 화면 확대 · 핀 · 다른 앱까지 고르는 캡처 · 자동 백업을 쓸 때만 필요합니다.

맥에서 앱이 “확인되지 않은 개발자” 라며 안 열려요.

시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 그래도 열기. 윈도우의 파란 PC 보호 화면은 추가 정보 → 실행. 개인이 만든 무료 앱이라 유료 인증서가 없어서 뜨는 안내입니다.

PIN을 잊어버렸어요.

확장을 지우고 다시 설치한 뒤, 첫 화면에 뜨는 가장 최근 백업으로 복구로 메모 · 북마크를 살리세요(자동 백업이 켜져 있었다면).
