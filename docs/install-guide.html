browser-sheriff-extension-{{VERSION}}.zipChrome 확장 + 발표 도우미 앱(맥·윈도우) 내장이 파일 하나면 됩니다
발표 도우미 앱이 확장 안에 들어 있습니다. 따로 파일을 받을 필요가 없습니다. 확장을 설치한 뒤 사이드바 발표 탭의 발표 프로그램 다운로드를 펼쳐 누르면 됩니다.

확장만 설치해도 메모·북마크·잠금·타이머·뽑기 같은 기능은 모두 됩니다. 발표 도우미 앱은 화면을 확대하거나 화면 조각을 붙일 때만 필요합니다.

1단계 · Chrome 확장 설치 맥 · 윈도우 공통

  1. browser-sheriff-extension-{{VERSION}}.zip 의 압축을 풉니다. 폴더가 하나 생깁니다.
  2. 이 폴더를 지우거나 옮기면 확장이 사라집니다.
    바탕화면 말고 문서 폴더처럼 계속 둘 곳에 놓아 주세요. 나중에 청소하다 지우기 쉽습니다.
  3. Chrome 주소창에 chrome://extensions 를 입력해 엽니다.
  4. 오른쪽 위 개발자 모드를 켭니다.
  5. 왼쪽 위 압축해제된 확장 프로그램을 로드를 누르고, 방금 압축을 푼 폴더를 고릅니다.
    (폴더 안의 파일이 아니라 폴더 자체를 고릅니다. 안에 manifest.json 이 보이는 그 폴더입니다.)
  6. 주소창 오른쪽 퍼즐 조각 아이콘 → 다있쌤 옆 압정을 눌러 고정합니다.
  7. 고정된 아이콘을 누르면 오른쪽 사이드 패널이 열립니다. 처음에는 프로필 이름과 PIN(숫자 4~12자리)을 정합니다. 잠금이 필요 없으면 PIN 없이 바로 쓰기 · 게스트를 누르면 됩니다.
Chrome을 켤 때마다 “개발자 모드 확장 프로그램을 사용 중지하세요” 라는 알림이 뜰 수 있습니다. X 를 눌러 닫으면 됩니다. 확장은 그대로 동작합니다. (Chrome 웹 스토어를 거치지 않고 직접 설치할 때 늘 나오는 안내입니다.)

2단계 · 발표 도우미 앱 맥

  1. 사이드바 발표 탭 → 발표 프로그램 다운로드 → 맥용 내려받기를 누릅니다. 내려받은 ZIP의 압축을 풉니다.
  2. 나온 Browser Sheriff Presenter 앱을 응용 프로그램 폴더로 옮깁니다.
  3. 두 번 눌러 엽니다. “악성 소프트웨어인지 확인할 수 없어 열 수 없습니다” 라고 나오면:
    • 시스템 설정 → 개인정보 보호 및 보안 을 열고 아래로 내려 보면 “…이(가) 차단되었습니다” 와 함께 [그래도 열기] 단추가 있습니다. 그걸 누릅니다.
    • (예전 macOS라면 앱을 오른쪽 클릭 → 열기 로도 됩니다.)
  4. 열리면 메뉴 막대(화면 맨 위 오른쪽)에 돋보기 아이콘이 생깁니다.
  5. 그 아이콘을 누르고 클립보드 도우미 → 등록 을 고릅니다.
    이걸 해야 사이드바의 발표·핀 단추가 앱에 말을 걸 수 있습니다.
  6. Chrome을 완전히 껐다가 다시 켭니다.
  7. 발표를 처음 시작하면 화면 기록 권한을 묻습니다. 허용하고, 앱을 한 번 껐다 켜 주세요.
    시스템 설정 → 개인정보 보호 및 보안 → 화면 기록
앱을 다른 폴더로 옮기면 메뉴 막대 → 클립보드 도우미 → 등록을 다시 해 주세요. 옮긴 자리를 다시 알려 줘야 합니다.

3단계 · 발표 도우미 앱 윈도우

  1. 사이드바 발표 탭 → 발표 프로그램 다운로드 → 윈도우용 내려받기를 누르고, 받은 ZIP의 압축을 반드시 풉니다.
    압축 파일 안에서 바로 실행하면 설치가 되지 않습니다. 파일이 커서(약 154MB) 푸는 데 잠시 걸립니다.
  2. 푼 폴더에서 Install.cmd 를 두 번 누릅니다.
  3. “Windows의 PC 보호” 파란 화면이 뜨면 추가 정보 → 실행 을 누릅니다.
    돈을 내고 서명을 받지 않은 프로그램에는 항상 나오는 화면입니다.
  4. “설치했습니다 — 버전 {{VERSION}}” 이라고 나오면 성공입니다.
  5. Chrome을 완전히 껐다가 다시 켭니다.
잘 안 될 때 — 같은 폴더의 Check.cmd 를 실행하면 어디서 막혔는지 알려 주고, 바탕화면에 다있쌤-점검.txt 로 남겨 줍니다. 그 내용을 보내 주시면 됩니다.

가상 컴퓨터(VMware 등)에서는 화면 확대가 안 될 수 있습니다. 가상 화면 드라이버가 Windows 확대 기능을 지원하지 않기 때문입니다. 그때도 화면 조각 핀은 정상으로 작동합니다.

업데이트할 때

확장새 ZIP을 풀어 기존 폴더에 덮어쓰기 → chrome://extensions 에서 새로고침(↻)
맥 앱메뉴 막대 → 앱 종료 → 새 앱을 응용 프로그램에 덮어쓰기 → 다시 열기
윈도우 앱트레이 아이콘 → 앱 종료 → 새 ZIP 풀고 Install.cmd

모니터가 여러 대일 때

  • 맥: 마우스를 다른 모니터로 옮기면 발표가 그 화면으로 따라갑니다. 화면마다 따로 잡아야 해서 옮길 때 잠깐(1초 안팎) 끊깁니다.
  • 윈도우: 집중 모드·포인터 원·화면 조각 핀은 모든 모니터에서 됩니다. 다만 화면 확대는 주 모니터에서만 됩니다 — Windows 자체의 제약이라 우회할 수 없습니다. 다른 화면을 확대하려면 Windows 디스플레이 설정에서 그 모니터를 주 모니터로 바꿔 주세요.

개인정보는 어떻게 되나요

  • 서버가 없습니다. 회원가입도, 로그인도, 사용 기록 수집도 없습니다.
  • 바깥으로 내보내는 코드가 아예 없습니다. 확장과 앱 어디에도 인터넷으로 자료를 보내는 코드가 들어 있지 않습니다.
  • 메모와 북마크는 본인의 Google 계정 Chrome 동기화 저장소에만 저장됩니다. 만든 사람은 볼 수 없습니다.
  • 캡처·녹음·웹캠 영상은 그 컴퓨터에만 남습니다. 동기화하지 않습니다.
  • PIN은 그 컴퓨터 안에서만 확인하며, 원문을 저장하지 않습니다.
  • 설치 파일에는 만든 사람의 이름·계정·컴퓨터 이름·폴더 경로가 들어 있지 않습니다. 확인했습니다.
