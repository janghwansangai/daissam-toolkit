다있쌤은 무엇을 해 주나요
교실에서 브라우저로 수업할 때 필요한 것들을 한곳에 모았습니다 — 화면 크게 보여 주기 · 화면 조각 붙여 두기 · 화면 캡처 · 화면 녹화 · 빠른 메모 · 북마크 · 프로필 잠금 · 타이머와 뽑기.

모두 이 컴퓨터 안에서만 돌아갑니다. 서버도 회원가입도 없고, 캡처한 그림이나 녹화한 영상이 밖으로 나가는 길이 없습니다(메모·북마크만 Chrome 계정 동기화를 쓸 수 있습니다).

시작하기 — 두 가지만 기억하세요

  1. 사이드바: Chrome 툴바의 ✳ 다있쌤 아이콘을 누르면 오른쪽에 열립니다. 모든 기능이 여기 있습니다. (탭 다섯 개: 빠른 메모 · 북마크 · 캡처 · 발표 · 유틸리티)
  2. 도크: 사이드바 맨 위의 단추 줄입니다. 자주 쓰는 11가지를 한 번에 누릅니다. ⧉ 를 누르면 도크만 따로 떠서 사이드바를 닫고도 쓸 수 있습니다.
▶ ■ 발표 시작·종료화면을 크게 보여 줍니다
◉ 집중 모드마우스 주변만 밝게
⛶ 화면 조각잘라서 화면에 붙여 둡니다
◌ 클릭 통과붙여 둔 핀을 유리처럼
⨯ 핀 모두 닫기붙여 둔 것 정리
⧉ 도크만 띄우기사이드바 없이 쓰기

1. 화면을 크게 보여 주기 (발표)

교과서 글씨나 작은 그림을 뒤에 앉은 학생도 보게 합니다. 발표 도우미 앱이 필요합니다.

  • 켜기: 도크 ▶ 또는 발표 탭의 발표 시작. 끄기는 ■ 또는 Esc.
  • 배율: Ctrl+Alt(맥은 ⌃⌥) 를 누른 채 마우스 휠. 1~4배.
  • 집중 모드: 마우스 주변만 밝고 나머지는 어둡고 흐리게. 도크 ◉ 또는 Ctrl+Alt+F. 어둡기·흐림·동그라미 크기·색은 발표 탭에서 조절합니다.
  • 모니터가 여러 대면 마우스가 있는 모니터가 확대됩니다.

2. 화면 조각 붙여 두기 (핀)

화면의 한 부분을 잘라 늘 위에 뜨는 카드로 붙여 둡니다. 페이지를 넘겨도, 다른 앱으로 가도 그대로 남아 앞 장과 견주며 설명할 때 좋습니다.

  • 만들기: 도크 ⛶ 또는 Ctrl+Alt+S → 끌어서 고르기. 클립보드의 그림·글은 Ctrl+Alt+V.
  • 핀 다루기: 끌어서 이동, 휠 크기, Ctrl+휠 투명도, 두 번 누르기 접기, 오른쪽 클릭 전체 메뉴(그리기·잘라내기·복사·저장·회전·뒤집기), Esc 그 핀만 닫기.
  • 클릭 통과: 핀을 유리처럼 만들어 그 자리의 버튼을 그대로 누를 수 있습니다. 켠 뒤에는 핀 위에서 휠로 투명도를 바꿀 수 있고, 해제는 도크 ◌ · 앱 메뉴 · Ctrl+Alt+T.
  • 핀은 화면 녹화에 담깁니다. 녹화하면서 붙여 둔 자료를 함께 보여 줄 수 있습니다.

3. 화면 캡처 (사진)

사이드바 캡처 탭입니다. 저장 방식(편집기로 열기 / 폴더 저장 / 클립보드 복사 / 둘 다)을 먼저 고르고 쓰세요.

단추무엇을 찍나쓸 때
보이는 부분지금 보이는 웹페이지 화면가장 빠름
전체 페이지스크롤해서 끝까지 이어 붙임긴 글·표 전체
선택 영역웹페이지에서 끌어 고른 곳일부만
화면 영역 · 다른 앱 · 다른 모니터브라우저 밖 어디든, 다른 모니터도한글·PPT 화면
잠시 뒤 보이는 부분3·5·10초 뒤(화면에서 3-2-1 을 셉니다)메뉴 펼친 모습
글자 뽑기고른 곳의 글자를 읽어 글로그림 속 글 옮기기

  • 편집기에서는 자르기·네모·화살표·펜·글자·모자이크·번호를 더하고 PNG·JPG·PDF·인쇄·복사로 내보냅니다.
  • 찍을 때 사이드바가 저절로 닫힙니다(사이드바가 열려 있으면 페이지가 좁게 찍힙니다). 결과는 페이지 위에 잠깐 알려 주고, 사이드바는 확장 아이콘이나 도크의 ☰ 로 다시 엽니다.
  • 저장 위치: 바탕화면 › 캡처이미지 폴더.

4. 화면 녹화 (영상)

캡처 탭 아래 영상 칸입니다. 무엇을 담을지 먼저 고릅니다.

방식담기는 것카메라
전체 화면화면 전체 · 다른 앱 창 · Chrome 탭 (고르기 창에서 선택)화면에 동그란 내 모습이 뜨고 그대로 담깁니다
이 탭지금 보고 있는 웹페이지와 그 소리화면에도 보이고, 영상 안에도 동그랗게 담깁니다
선택 영역페이지에서 끌어 고른 곳만쓰지 않습니다
카메라만내 모습만—
  • 시작하면 3-2-1 을 세고(초는 설정에서), 그 숫자는 영상에 담기지 않습니다.
  • 녹화 중에는 작은 알약 모양 표시기가 뜹니다 — 지난 시간 · 일시 정지 · 멈추고 저장 · 취소. 끌어서 옮길 수 있고 이 창은 영상에 담기지 않습니다. 녹화 창(초록 창)은 저절로 내려갑니다.
  • 끝내면 미리 보기가 뜨고 내려받기 폴더에 저장을 누르면 MP4(또는 WebM)로 저장됩니다.
  • 마이크·소리·해상도(720p~4K)·최대 길이는 더 보기에서 정합니다.
Chrome 이 보호하는 페이지는 담을 수 없습니다 — 새 탭, chrome:// 설정, 확장 프로그램 관리, 웹 스토어. 그 화면에서는 ‘전체 화면’ 으로 녹화하세요(캡처도 같습니다).

5. 메모 · 북마크 · 잠금 · 유틸리티

  • 빠른 메모: 여러 개를 제목으로 골라 씁니다. 같은 Google 계정의 다른 컴퓨터와 동기화됩니다. 복사·캡처 자동 가져오기 를 켜면 복사한 그림이 메모에 붙습니다.
  • 북마크: 폴더로 정리하는 이 확장만의 목록입니다. 백업 내보내기·가져오기가 있습니다.
  • 프로필 잠금: 도크의 🔒 를 누르면 PIN 을 넣어야 다시 씁니다. 자리를 비울 때 자동 잠금도 됩니다. PIN 을 잊으면 확장 설정을 초기화해야 합니다. 이 컴퓨터에만 저장되고 어디로도 보내지 않습니다.
  • 유틸리티: 수업 타이머 · 이름 뽑기 · 수업 시보 · 화면 글꼴 바꾸기.
  • 전체 백업 · 복원: 메모·북마크·설정을 파일 하나로 저장했다가 다른 컴퓨터나 다른 Google 계정에서 불러옵니다(아래 6번).

6. 다른 컴퓨터 · 다른 Google 계정으로 옮기기 (백업과 복원)

같은 Google 계정이면 메모와 북마크가 알아서 따라옵니다. 계정이 다르거나(학교 계정 ↔ 개인 계정), 설정까지 통째로 옮기고 싶을 때, 또는 만일을 대비해 보관하고 싶을 때 백업 파일을 씁니다. 맥과 윈도우 사이도 됩니다.

백업 만들기

  1. 도크의 ⚙ (설정)을 누르고 맨 아래 전체 백업 · 복원으로 내려갑니다.
  2. 백업 암호로 파일 잠그기를 켜 둔 채(권장) 암호를 두 번 넣습니다. 8자 이상으로 정하세요.
  3. 전체 백업 만들기를 누르면 다있쌤-백업-날짜.json 이 내려받기 폴더에 저장됩니다. 파일을 만든 뒤 바로 다시 열어 확인까지 하므로, 저장됐다는 안내가 나오면 믿어도 됩니다.
백업 암호를 잊으면 파일을 열 수 없습니다. 이 암호는 어디에도 저장하지 않아서 저도 되찾아 드릴 수 없어요. 수첩이나 비밀번호 관리자에 적어 두세요.
무엇이 담기나요설명
메모모든 메모(동기화되지 못한 긴 메모 포함)와 붙여 둔 그림의 작은 미리보기
북마크북마크와 폴더
설정화면 글꼴, 캡처·녹화 옵션, 발표 조절값, 단축키, 잠금 옵션
수업 도구수업 시보(종 시각), 알람 소리, 모둠 점수
잠금 PIN암호를 건 백업에만 담깁니다. 새 컴퓨터에서 PIN 을 다시 정하지 않아도 같은 PIN 으로 열립니다

이 컴퓨터에서만 뜻이 있는 것(카메라·마이크 번호, 도크 창 자리, 실행 중인 타이머)과, 바탕화면 캡처이미지 폴더의 그림 파일은 담기지 않습니다. 그림 파일은 폴더째 직접 복사해 옮기세요. 암호를 끄고 저장하면 메모와 북마크가 그대로 읽히는 파일이 되고 잠금 PIN 은 담기지 않습니다.

복원하기

처음 설치한 새 컴퓨터라면 PIN 을 만드는 첫 화면에서 이미 백업이 있어요 · 백업에서 복원 을 누르고 파일을 고른 뒤 암호를 넣으세요. PIN 을 다시 정하지 않아도 바로 쓸 수 있고, 같은 PIN 으로 잠금이 풀립니다.

이미 쓰고 있는 컴퓨터라면 설정의 백업 파일 불러오기에서 파일을 고르고, 가져올 항목에 체크한 뒤 복원하기를 누릅니다. 다 끝나면 화면이 다시 열리면서 무엇을 가져왔는지 알려 줍니다.

  • 지금 있는 것은 지우거나 덮어쓰지 않습니다. 없는 메모·북마크만 더합니다.
  • 같은 메모인데 내용이 다르면 ‘제목 (백업)’ 이라는 사본으로 따로 넣습니다. 어느 쪽을 쓸지는 직접 고르세요.
  • 같은 파일을 여러 번 불러와도 늘어나지 않습니다. 중간에 실수로 한 번 더 눌러도 괜찮습니다.
  • 잠금 PIN 바꾸기는 이미 PIN 이 있는 컴퓨터에서는 기본으로 꺼져 있습니다. 켜면 지금 이 컴퓨터의 PIN 을 한 번 더 물어봅니다.
  • 북마크는 Chrome 동기화 한 칸(약 8KB)에 들어가는 만큼만 담깁니다. 넘치면 몇 개를 못 넣었는지 알려 주니, 안 쓰는 것을 정리하고 다시 불러오세요.

7. 단축키

8. 이럴 때는

녹화 고르기 창에서 ‘전체 화면·창’ 이 흐리게 나옵니다 (맥)

맥이 Chrome 에게 화면 기록을 아직 허락하지 않은 것입니다. 녹화 창의 시스템 설정 열기 를 누르고 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음 → Google Chrome 을 켠 뒤 Chrome 을 완전히 껐다 켜세요.

발표·핀 단추가 “발표 도우미에 연결하지 못했습니다” 라고 합니다

앱이 설치·등록되지 않았습니다. 설치 안내문의 2·3단계를 다시 해 주세요. 윈도우는 앱 폴더의 Check.cmd 를 실행하면 무엇이 빠졌는지 알려 줍니다.

사이드바가 사라졌습니다

캡처·녹화할 때 저절로 닫힙니다. 확장 아이콘(✳)을 다시 누르거나, 따로 띄운 도크의 ☰ 를 누르세요.

녹화 영상에 카메라가 안 보입니다

선택 영역 녹화는 카메라를 쓰지 않습니다. 다른 방식이라면 카메라 칸이 켜져 있는지, 그리고 맥에서는 다있쌤 발표 도우미 에 카메라 권한을 허락했는지 확인하세요(메뉴 막대 → 녹화 카메라 창 미리 보기 로 미리 허락할 수 있습니다).

캡처가 “이 탭은 캡처할 수 없습니다” 라고 합니다

새 탭·설정·확장 프로그램 관리·웹 스토어는 Chrome 이 막아 둔 화면입니다. 일반 웹페이지에서 하거나 화면 영역 · 전체 화면 을 쓰세요.

백업 파일이 “암호가 맞지 않거나 파일이 손상되었습니다” 라고 합니다

대부분 암호를 잘못 넣은 것입니다. 대소문자와 띄어쓰기, 한/영 상태를 확인하세요. 암호를 잃어버렸다면 그 파일은 열 수 없습니다. 그래서 암호 없는 백업도 하나 따로 만들어 두면 안전합니다(잠금 PIN 은 빠집니다). 파일이 중간에 잘렸거나 고쳐졌다면 같은 이유로 열리지 않습니다.

복원했는데 일부 메모·북마크가 동기화되지 않습니다

Chrome 동기화에는 한 번에 쓸 수 있는 양과 횟수 제한이 있습니다. 메모가 많으면 일부가 잠시 기다렸다가 1분마다 자동으로 올라갑니다. 5,500바이트(한글 약 1,800자)보다 긴 메모는 동기화되지 않고 이 컴퓨터에만 남습니다. 그래도 목록에는 모두 보입니다.

업데이트했는데 예전처럼 동작합니다

chrome://extensions 에서 다있쌤의 새로고침을 누르세요. 그래도 그러면 Chrome 을 껐다 켭니다. 앱도 새 버전을 설치했는지 확인하세요(맥은 설치 스크립트, 윈도우는 Install.cmd).
