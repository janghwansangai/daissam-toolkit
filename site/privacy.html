다있쌤(이하 '이 확장 프로그램')은 선생님의 수업을 돕는 Chrome 확장 프로그램입니다. 이 확장 프로그램은 개발자가 운영하는 서버가 없으며, 사용자의 정보를 개발자에게 보내거나 수집하지 않습니다.

1. 저장하는 정보와 장소

- 메모, 북마크, 설정, 수업 도구 설정: 사용자의 Chrome 저장소에 저장됩니다. 사용자가 Chrome 동기화를 켜 두었다면 Google 계정의 Chrome 동기화를 통해 같은 계정의 다른 컴퓨터로 옮겨집니다.

- 잠금 PIN: 원래 숫자가 아닌 변환된 값(해시)으로만 이 컴퓨터에 저장됩니다.

- 캡처 이미지와 녹화 파일: 이 컴퓨터의 바탕화면 '캡처이미지' 폴더 또는 사용자가 고른 곳에만 저장되며 동기화하지 않습니다.

- 백업 파일: 사용자가 직접 만들고 보관합니다. 암호를 걸면 그 암호 없이는 열 수 없습니다.

2. 개발자에게 보내는 정보

없습니다. 이 확장 프로그램은 광고, 분석, 사용 통계 도구를 쓰지 않으며, 어떤 정보도 개발자나 제3자에게 보내지 않습니다.

3. 웹페이지 접근

화면 캡처와 프로필 잠금 기능이 사용자가 여는 페이지에서 동작하도록 웹페이지에 접근합니다. 페이지 내용을 저장하거나 외부로 보내지 않습니다. 캡처는 사용자가 단추를 누를 때만 합니다.

4. 발표 도우미 앱

선택해서 설치하는 발표 도우미 앱(맥·윈도우)은 같은 컴퓨터 안에서만 확장 프로그램과 대화하며 인터넷으로 정보를 보내지 않습니다.

5. 정보 삭제

확장 프로그램을 제거하면 이 컴퓨터의 저장 정보가 지워집니다. 동기화된 정보는 Chrome 설정의 동기화 데이터 삭제로 지울 수 있습니다. 캡처 파일은 '캡처이미지' 폴더에서 직접 지우면 됩니다.
