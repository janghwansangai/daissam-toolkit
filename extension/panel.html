캡처 세부 설정

사이드바가 열려 있으면 페이지가 그만큼 좁아져 캡처도 좁게 찍힙니다. 자동으로 닫고 찍은 뒤 사이드바를 다시 열어 결과를 알려 줍니다. 열지 못하면 페이지 위에 잠깐 뜨는 안내와 알림으로 알려 드립니다.

카메라를 켜면 녹화 영상 오른쪽 아래에 동그란 내 모습이 함께 담깁니다(화면에 뜨는 창은 없습니다).

카메라를 띄우면 화면 오른쪽 아래에 동그란 창으로 내 모습이 보이고, 전체 화면 녹화에는 그 모습이 그대로 담깁니다. 탭·선택 영역 녹화에서는 창 대신 영상 안에 합쳐 넣습니다.

도크의 두 단추(선택 영역 · 스크롤 캡처)는 이 설정과 상관없이 늘 바탕화면 ‘캡처이미지’ 폴더에 저장하고 클립보드에 복사합니다 — 바로 붙여넣을 수 있습니다.

캡처는 이 컴퓨터 안에서만 처리하며 어디로도 올리지 않습니다. 새 탭·Chrome 설정·웹 스토어 화면은 Chrome 이 캡처를 막아 둡니다. 저장·복사·글자 뽑기는 발표 도우미 앱이 합니다.

화면 조각 핀 안내

화면의 한 부분을 잘라 늘 위에 뜨는 카드로 붙여 둡니다. 페이지를 넘기거나 다른 앱으로 가도 카드는 그대로 남아, 앞 장과 견주며 설명할 때 좋습니다. 글을 복사해 붙이면 쪽지처럼 붙습니다.

조각 위에 그리기: 핀에 마우스를 올리면 뜨는 ✎ 단추(또는 d 키, 오른쪽 클릭 메뉴)를 누르면 아래에 도구 줄이 나옵니다. 고르기(↖) · 펜 · 원 · 밑줄 · 모자이크 · 글자 여섯 가지이고, 색은 7칸(마지막 칸은 누르면 색 고르개가 열려 원하는 색을 직접 만듭니다)에 굵기·글자 크기를 3단계로 고릅니다. 글자(T)는 누른 자리에 커서가 깜빡이는 글상자가 열립니다 — 한글·일본어·중국어가 그대로 조합되고, Return은 줄바꿈, Esc로 마칩니다. 쓰는 도중 일부를 끌어 고른 뒤 색 칸을 누르면 그 부분만 색이 바뀌고, 고른 것이 없으면 글 전체가 바뀝니다. 마치기 전까지 쓴 글을 한 번 누르면 다시 고쳐 쓰고, 끌면 옮기며, 오른쪽 아래 ⇲를 끌면 크기가, 오른쪽 위 ✕를 누르면 그 글상자만 지워집니다. 고르기(↖)를 켜면 이미 그린 줄·원·밑줄·모자이크·글자를 눌러 고르고, 끌어 옮기고, 네 모퉁이 손잡이로 크기를 바꾸고, 오른쪽 위 ✕나 Delete로 지웁니다. 글자를 고른 채 제자리에서 떼면 다시 고쳐 쓰기로 들어갑니다. ↶로 되돌리고 그 옆 ✓ 마침(또는 Return·Esc)을 누르면 그린 것까지 그림에 들어갑니다 — 그 뒤 복사·저장·자르기에 그대로 따라옵니다. Esc는 그리기만 취소합니다.

모퉁이로 다시 자르기: 핀에 마우스를 올리면 뜨는 ⛶ 단추(또는 x 키, 오른쪽 클릭 메뉴)를 누르면 네 모퉁이에 손잡이가 생깁니다. 모퉁이를 끌어 남길 부분을 정하고 Return으로 자릅니다. 안쪽을 끌면 통째로 옮기고, 바깥을 끌면 새로 잡습니다. Esc는 자르기만 취소합니다(핀은 닫히지 않습니다).

핀 위에서 휠은 크기, Command/Ctrl + 휠은 투명도, 두 번 누르기는 접기, 오른쪽 클릭은 전체 메뉴(자르기·복사·저장·회전·뒤집기·클릭 통과), Esc는 그 핀만 닫기입니다. 끌어서 어디든 옮길 수 있습니다.

핀은 확대·집중 모드에 휩쓸리지 않습니다. 화면을 4배로 키우거나 바깥을 흐리게 해도 핀은 같은 크기로 또렷하게 위에 남습니다. 조각을 자르는 동안에만 확대가 잠시 원래 크기로 돌아갔다가 되돌아옵니다.

단축키는 발표 중에만 듣습니다. 발표 전에는 이 버튼이나 앱 메뉴(macOS 메뉴 막대 · Windows 트레이)를 쓰세요. 저장은 바탕화면 아래 ‘캡처이미지’ 폴더에 ‘다있쌤-핀-…png’로 남고, 복사한 뒤 메모의 자동 가져오기가 켜져 있으면 메모에도 들어갑니다.

발표 도우미 안내

바탕화면과 다른 앱까지, 움직이는 화면 그대로 확대합니다. 발표 도우미 앱을 함께 설치해 주세요.

집중 모드에서는 포인터 둘레의 원을 그리지 않습니다. 밝은 집중 원이 이미 포인터 자리를 가리켜서 두 겹으로 보이기 때문입니다. 아래 ‘포인터 원 크기·색’은 집중 모드가 꺼진 확대 화면에 적용됩니다.

버튼과 조절값은 발표 도우미 앱으로 바로 전달됩니다. 앱이 꺼져 있으면 ‘발표 시작’이 앱을 먼저 켭니다. macOS와 Windows 모두 이 도크와 버튼으로 조작합니다.

켜 두면 컴퓨터를 켜고 Chrome을 열었을 때 항상 잠긴 상태로 시작합니다. 끄면 다시 열어도 풀린 상태가 유지됩니다(권장하지 않음).

이것만 따로 끌 수 있습니다. 끄면 부팅할 때는 그대로 잠기지만, 잠깐 자리를 비웠다 돌아왔을 때는 다시 PIN을 묻지 않습니다.

macOS에는 없는 기능을 채웁니다. Command 키를 누른 채 휠을 굴리면 Command + +/− 와 똑같은 단계로 페이지가 커지고 작아집니다. Chrome 기본 배율 단계를 그대로 쓰므로 Command + 0 으로 원래대로 돌아갑니다. Windows는 Ctrl + 휠이 이미 같은 일을 하므로 켜도 달라지지 않습니다.

윈도우에 설치된 글꼴(맑은 고딕·굴림·돋움)은 작은 글씨에 맞춰 손으로 다듬어져 있어 웹 글꼴보다 선이 또렷합니다. 흐리게 퍼져 보이면 맑은 고딕이나 굴림을 골라 보세요. 없는 글꼴을 고르면 기본으로 돌아갑니다. 이 설정은 이 컴퓨터에만 적용됩니다.

글자가 붙어 보이면 오른쪽으로, 너무 벌어져 보이면 왼쪽으로 옮기세요. 0.1px 씩 움직입니다. 맑은 고딕·굴림·돋움을 고르면 맥 글꼴에 맞춰 두었던 좁은 자간을 먼저 0 으로 되돌린 뒤 이 값을 더합니다.

체크와 선택은 바꾸는 즉시 저장됩니다. 잠금 설정은 컴퓨터마다 따로 기억하며, 다른 컴퓨터와 동기화되지 않습니다.

브라우저를 다시 시작하면 잠깁니다. 북마크 바와 Chrome 내부 화면은 가려지지 않습니다.
