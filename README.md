# 다있쌤

공유 컴퓨터에서 다른 사람의 Chrome 프로필을 실수로 계속 사용하는 것을 막는 확장과 전체 화면 발표 도우미입니다. 자체 서버·회원가입·사용 분석 수집이 없습니다.

## 설치

### Chrome 확장 · macOS / Windows
1. `dist/release/browser-sheriff-extension-0.28.0.zip`을 원하는 폴더에 압축 해제합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**에서 그 폴더를 선택합니다. 소스로 실행할 때는 이 저장소의 `extension` 폴더를 선택합니다.
3. 확장 아이콘을 고정합니다. 아이콘을 누르면 오른쪽 사이드 패널이 열립니다(좌우 위치는 Chrome 설정을 따르며 확장이 강제할 수 없습니다). 프로필 이름과 숫자 6~12자리 PIN을 정하세요. 이 PIN은 해당 기기에만 저장됩니다.
4. 다른 컴퓨터에도 같은 ZIP을 설치하고, 같은 Google 계정의 Chrome 동기화에서 확장 프로그램 동기화를 켭니다. 웹사이트 Google 로그인만으로는 동기화되지 않습니다.

개발용 확장 ID는 `ehgodopakibamgeopmelemjmjdjhbdgm`입니다. manifest의 공개 키로 두 OS에서 같은 ID를 유지합니다. 비밀 키는 포함하지 않습니다. 향후 Chrome Web Store 등록은 별도 작업이며, 스토어 ID가 바뀌면 데이터 이전을 확인해야 합니다. 이 패키지는 스토어에 게시되지 않은 테스트 배포본입니다.

### 발표 도우미
- **macOS 13 이상 (Apple Silicon / Intel):** macOS ZIP을 풀어 `Browser Sheriff Presenter.app`을 **응용 프로그램 폴더 한 곳에만** 넣습니다. 소스에서 빌드했다면 `bash presenter/macos/install.sh`가 설치와 권한 초기화를 함께 처리합니다.
- **서명이 바뀌면 권한을 한 번만 다시 줍니다.** macOS는 권한을 앱의 서명에 묶습니다. 임시 서명에서 고정 인증서 서명으로 넘어가는 순간 옛 기록이 맞지 않게 되므로, `install.sh`가 그때 한 번만 기록을 지우고 안내합니다. 시스템 설정의 목록에 **옛 항목이 남아 있으면 `−`로 지우고 새로 뜨는 항목만 켜세요.** 고정 인증서로 서명한 뒤에는 다시 빌드해도 묻지 않습니다.
- **앱을 두 벌 두지 마세요.** macOS는 화면 기록 권한을 앱의 **경로별로** 기록합니다. 같은 앱이 두 곳에 있으면 권한은 한쪽에만 붙고, 다른 쪽을 실행하면 "권한을 허용하세요"가 계속 뜹니다. 복사본은 지우고 한 곳에서만 실행하세요. 두 벌이 동시에 실행되면 앱이 알려 주고 두 번째는 바로 종료됩니다.
- **버튼은 어떤 것도 잠그지 않습니다.** 앱이 화면 기록을 준비하는 데 시간이 걸려 상태를 늦게 알려 주면, 잠긴 버튼은 영영 눌리지 않습니다. `집중 모드`도 항상 누를 수 있고, 발표 전에 누르면 앱이 "발표를 먼저 시작해 주세요"라고 알려 줍니다.
- **버튼은 앱의 실제 상태를 색으로 보여 줍니다.** 발표 중이면 `발표 종료`가, 발표 전이면 `발표 시작`이 진하게 표시됩니다. `발표 시작`과 `발표 종료`는 **어떤 경우에도 잠기지 않습니다**(상태를 잘못 읽어 발표를 끄지 못하게 갇히면 안 되기 때문). 발표 중에만 쓸 수 있는 `집중 모드`만 비활성화됩니다. Esc로 직접 끝내도 사이드바를 다시 열면 상태가 맞춰집니다.
- **발표 조작은 사이드바에서도 됩니다.** 발표 탭의 `발표 시작` / `발표 종료` 버튼과 `집중 모드 켜기 · 끄기` **토글**, 그리고 아래 조절값(집중 모드 어둡기·흐림, 포인터 원 크기·색)이 앱으로 바로 전달됩니다. Esc가 다른 프로그램과 겹칠 때 쓰세요. 앱이 꺼져 있으면 `발표 시작`이 앱을 먼저 켭니다. **Windows는 아직 트레이 메뉴와 단축키로만 조작합니다.**
- **권한을 한 번만 주려면 두 스크립트를 순서대로 한 번씩 실행하세요.**
  1. `bash presenter/macos/make-signing-cert.sh` — 인증서를 만듭니다.
  2. `bash presenter/macos/allow-signing-key.sh` — 키체인이 서명할 때마다 승인 창을 띄우지 않게 합니다. **Mac 로그인 암호를 묻습니다.** 이 단계를 건너뛰면 빌드가 서명에서 멈추므로, 25초 기다린 뒤 임시 서명으로 넘어갑니다(그 경우 빌드할 때마다 권한을 다시 줘야 합니다). 이 Mac에서만 쓰는 자체 서명 인증서를 만들어 로그인 키체인에 넣고, 그 인증서를 **코드 서명 용도로만** 신뢰합니다. 이후 빌드는 그 인증서로 서명되어 **다시 빌드해도 화면 기록·손쉬운 사용 권한이 유지됩니다**(서명 요구사항이 인증서에 고정되기 때문).
  - 지우려면: `security delete-certificate -c "Browser Sheriff Local Signing" ~/Library/Keychains/login.keychain-db`
  - 인증서 없이 빌드하면 예전처럼 임시(ad-hoc) 서명이 되고, 빌드할 때마다 권한을 다시 줘야 합니다. `install.sh`가 그 경우에만 옛 권한 기록을 지웁니다.
  - Apple 개발자 계정과는 무관합니다. 이 인증서로 서명한 앱도 다른 Mac에서는 여전히 미확인 개발자 앱입니다. 앱을 열면 메뉴 막대 오른쪽에 돋보기 아이콘이 생깁니다. 그 아이콘에서 ‘발표 시작’을 선택하세요. 메뉴 막대가 가득 차 아이콘이 보이지 않으면 Command 키를 누른 채 다른 아이콘을 옮겨 자리를 만드세요. 화면 기록·손쉬운 사용 권한은 시스템 설정에서 직접 허용해야 합니다. 현재 빌드는 개발용 임시 서명이며 Apple 공증을 받지 않았습니다.
- **Windows 10/11 x64:** Windows ZIP을 풀고 `Presenter.exe`를 실행합니다. .NET 별도 설치가 필요 없는 빌드입니다. `Install.cmd`를 실행하면 사용자 계정에 확장 연결 주소를 등록합니다(관리자 권한 불필요). 앱은 `%LOCALAPPDATA%\BrowserSheriff`에 복사됩니다. 현재 EXE는 코드 서명되지 않았습니다.
- 설치 후 확장의 **발표 → 발표 도우미 열기**로 실행할 수 있습니다. 서버나 로컬 네트워크 포트를 사용하는 연결이 아니라 `browsersheriff://presenter` 앱 주소입니다.
### 복사·캡처 자동 가져오기
1. 발표 도우미 앱을 설치합니다. macOS는 `bash presenter/macos/install.sh`가 설치와 **클립보드 도우미 등록을 함께** 처리합니다(앱을 직접 옮겼다면 메뉴 막대 아이콘 → **클립보드 도우미 → 등록**). Windows는 `Install.cmd`가 함께 등록합니다.
   - 등록 파일은 macOS `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/app.browsersheriff.presenter.json`, Windows는 `HKCU\Software\Google\Chrome\NativeMessagingHosts`입니다. 토글이 **"Specified native messaging host not found"**로 꺼지면 이 등록이 없는 것입니다.
   - 앱을 다른 폴더로 옮기면 등록에 적힌 경로가 어긋나므로 다시 등록해야 합니다.
2. 확장 사이드 패널의 메모 위 **복사·캡처 자동 가져오기** 토글을 켭니다. 기본값은 꺼짐이며, **켠 뒤에 복사하거나 캡처한 것만** 가져옵니다.
3. 가져온 것은 **그때마다 새 메모**로 저장되며 이름은 `자동저장1`, `자동저장2` … 로 붙습니다. 연속으로 복사·캡처해도 한 메모에 섞이지 않습니다.
   - 클립보드로 복사한 이미지는 **바탕화면에 `다있쌤-캡처-날짜-시각.png`로 저장**됩니다.
   - macOS 기본 캡처(`⌘⇧4`)처럼 **바탕화면에 파일로 저장되는 캡처도 함께 감지**합니다. 켠 뒤에 새로 생긴 `스크린샷…png` / `Screenshot…png`만 가져옵니다.
   - 메모에는 작은 미리보기만 남고 원본은 바탕화면 파일입니다.
4. 미리보기 옆 **복사**를 누르면 도우미가 그 PNG를 클립보드에 올려 다른 앱에서 Ctrl+V로 붙일 수 있습니다.
- 가져온 캡처는 메모 아래 **‘가져온 캡처’에 미리보기로 바로 보입니다.** 가져오는 순간 그 메모로 화면이 넘어갑니다(글을 쓰는 중이면 넘어가지 않습니다).
- 이미지는 동기화하지 않습니다. 미리보기는 메모당 12장, 전체 40장까지 보관하며 오래된 것부터 목록에서 빠집니다. 바탕화면 파일은 지우지 않습니다.
- 프로필을 잠그면 연결이 끊어지고 수집이 멈춥니다. 토글을 끄면 도우미 프로세스도 종료됩니다.
- **주의:** 켜 둔 동안에는 비밀번호처럼 민감한 내용이 클립보드에 들어오면 그대로 메모에 남습니다. 필요할 때만 켜세요.
- 도우미는 바탕화면의 `다있쌤-캡처-*.png`만 다시 읽습니다. 다른 파일은 열지 않습니다. 파일로만 저장되는 캡처는 클립보드에 오르지 않아 가져오지 않습니다.

- **발표 중 조작은 키보드로 합니다.** 발표를 시작하면 확대 화면이 메뉴 막대·작업 표시줄을 덮으므로 메뉴를 쓸 수 없습니다.
  - `Control + Option/Alt + P` **발표 시작 · 종료** — 앱이 켜져 있으면 발표 전에도 듣습니다. 한 키로 켜고 끕니다.
  - `Control + Option/Alt + 휠` 1~4배 확대 · 축소
  - `Control + Option/Alt + F` 집중 모드 켜기 · 끄기
  - `Control + Option/Alt + Shift + 휠` 집중 모드 원 크기
  - `Esc` 원래 크기로, **한 번 더 누르면 발표 종료**
  - `Control + Option/Alt + S` 화면 조각을 잘라 붙이기 · `+ V` 클립보드 붙이기 · `+ D` 핀 모두 닫기 · `+ T` 클릭 통과 해제
  - 화면 아래에 현재 배율과 이 키들이 항상 표시됩니다.
- **단축키는 바꿀 수 있습니다.** 사이드바 발표 탭 → `단축키 안내 · 바꾸기` 에서 키 칸을 누르고 새 조합을 그대로 누르면 됩니다. 위 여섯 가지(발표 시작·종료 · 집중 모드 · 화면 조각 · 클립보드 · 핀 닫기 · 클릭 통과)가 대상이고, 휠과 `Esc` 는 고정입니다.
  - **맥과 윈도우를 따로 정합니다.** 두 운영체제가 미리 가져간 조합이 다르기 때문입니다. 한쪽에서 두 벌을 다 정해 둘 수 있고, 각 컴퓨터는 자기 벌만 앱에 보냅니다.
  - **운영체제가 쓰는 조합은 고를 수 없게 막습니다** — 맥은 Command(⌘) 조합 전체·Option+Shift(특수문자), 윈도우는 Windows(⊞) 키 조합 전체·Alt+Shift(키보드 배열 바꾸기), 양쪽 모두 F1~F12 와 수정 키 하나만 쓰는 조합. 윈도우의 `Ctrl+Shift` 는 고를 수는 있지만 Chrome 과 겹친다고 알려 줍니다.
  - 정한 조합은 앱에도 남습니다(맥 `UserDefaults`, 윈도우 `%LOCALAPPDATA%\BrowserSheriff\keys.txt`). 앱만 따로 켜도 지난번 조합이 그대로 듣습니다.
- **포인터:** 실제 마우스 커서는 그대로 두고 둘레에 반투명 원만 그립니다. 커서를 두 개로 그리지 않으므로 겹쳐 보이지 않습니다.
- **집중 모드는 혼자서도 켜집니다.** 발표를 먼저 시작하지 않아도 됩니다 — 누르면 발표를 함께 켜고 바로 집중 모드로 들어갑니다. 예전에는 "발표를 먼저 시작하세요" 경고창이 떴고, **그 창이 떠 있는 동안 사이드바 명령이 전부 먹통이 됐습니다.**
- **집중 모드:** 포인터 둘레의 원만 남기고 바깥을 가립니다. macOS는 흐리게, Windows는 어둡게 처리합니다(Windows 확대 API가 화면 픽셀을 내주지 않아 흐림을 쓸 수 없습니다). **집중 모드에서는 포인터 둘레의 원을 그리지 않습니다** — 밝은 집중 원이 이미 포인터 자리를 가리켜 두 겹으로 보이기 때문입니다.
### 캡처 (v0.30.0)

사이드바 **‘캡처’ 탭**. 어썸 스크린샷(Awesome Screenshot)의 기능을 참고했고, 클라우드 대신 **이 컴퓨터에만** 저장합니다. 위는 사진, 아래는 영상 — 누를 것은 모두 펼쳐 둡니다.

- **사진**: 보이는 부분 · 전체 페이지(스크롤하며 이어 붙이기, 최대 32,000px) · 선택 영역 · 잠시 뒤(3·5·10초) · 전체 화면·앱 창 · 내 사진·클립보드 이미지 꾸미기 · 캡처하고 글자 뽑기(OCR).
- **캡처 후**: 편집기에서 꾸미기 / ‘캡처이미지’ 폴더 저장 + 복사 / 폴더에 저장 / 클립보드에 복사.
- **편집기**: 고르기·옮기기 · 자르기 · 사각형 · 원 · 화살표 · 선 · 펜 · 형광펜 · 글자(한글 입력, 바탕색, 크기 4단계) · 흐리게(모자이크) · 번호 ①②③ · 색 7개(마지막은 직접 고르기) · 굵기 3단계 · 되돌리기/다시 하기 · 크기 바꾸기. 내보내기: ‘캡처이미지’ 폴더 저장 · 복사 · PNG/JPG/PDF 내려받기 · 인쇄 · 글자 뽑기. 단축키 V C R O A L P H T B N, ⌘/Ctrl+Z·S·C, Shift 로 정사각형·수평선.
- **영상**: 전체 화면 · 카메라만 · 이 탭 · 선택 영역(이 탭). 카메라 얼굴을 오른쪽 아래 동그라미로 함께 담기, 마이크 고르기, 컨트롤 바(작은 창: 시간·일시 정지·마이크 끄기·멈춤), 720p/1080p/2K/4K, MP4/WebM, 카운트다운, 자동 멈춤, 탭·컴퓨터 소리. 끝나면 미리 보고 내려받기 폴더에 저장.
- **도크의 두 단추**: 선택 영역 캡처 · 스크롤(전체 페이지) 캡처 — 설정과 상관없이 **바탕화면 ‘캡처이미지’ 폴더에 저장하고 클립보드에 복사**합니다. 바로 붙여넣을 수 있습니다.
- **단축키**: `chrome://extensions/shortcuts` 에서 ‘캡처 — 선택 영역·전체 페이지·보이는 부분’ 에 키를 정합니다(기본 키는 비워 둠).
- 저장·복사·글자 뽑기는 **발표 도우미 앱**이 합니다(확장은 바탕화면에 쓸 수 없고 서비스 워커는 클립보드를 만질 수 없음). 앱이 없거나 옛 버전이면 그림을 버리지 않고 편집기로 엽니다.
- 새 탭·Chrome 설정·웹 스토어는 Chrome 이 캡처를 막습니다. 다른 창에 가려진 탭은 예전 화면이 찍히므로 찍지 않고 알려 줍니다.

### 녹화 표시기 · 카메라 동그라미 · 도크 분리 (v0.31.0 · v0.32.0)

- **녹화 표시기**: 녹화를 시작하면 작은 알약 모양 창이 뜬다 — ● 지난 시간 · 일시 정지 · 멈추고 저장 · 취소. **화면 녹화에 담기지 않는다**(맥 `NSWindow.sharingType = .none`, 윈도우 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`). 아무 곳이나 끌어 옮길 수 있고 둔 자리를 기억한다. 발표 도우미 앱이 그린다.
- **녹화 창은 시작과 함께 내려간다**(v0.32.0): 초록 창이 화면에 남아 녹화에 함께 담기지 않도록. 조작은 표시기가 맡는다. 표시기가 없으면(앱 미설치) 창을 그대로 두고 그렇게 알린다. 내린 창은 타이머가 느려지므로 시계는 녹화기의 1초 조각 이벤트로도 민다.
- **카메라 동그라미**(v0.33.0): 전체 화면 녹화에서 카메라를 켜면 **발표 도우미 앱이 동그란 카메라 창**을 화면에 띄운다 — 테두리도 제목 표시줄도 없는 진짜 원이고(브라우저 창으로는 못 만든다), 끌어서 옮길 수 있으며 **녹화에 그대로 담긴다**. 앱이 못 띄우면(카메라 권한 전·앱 없음·탭/선택 영역 녹화) 예전처럼 **영상 안에** 동그랗게 합쳐 넣는다. 두 개가 겹치지 않도록 확장이 앱 상태를 확인하고 하나만 고른다.
- **카메라 권한**(맥): 처음에는 카메라 물음이 뜨고 그 녹화에서는 창을 띄우지 않는다(늦게 떠서 두 개가 되는 것을 막는다). 메뉴 막대 → **녹화 카메라 창 미리 보기**로 미리 허용해 두면 다음 녹화부터 바로 보인다.
- **전체 화면 고르기**(v0.33.0): 녹화 창의 **‘화면 고르기’ 를 누른 그 손길로** 브라우저 표준 고르기(`getDisplayMedia`)를 연다. 확장 API 로 열던 고르기 창은 초점이 흔들리면 **목록이 비거나** 그대로 닫혔다.
- **캡처·녹화할 때 사이드바 자동 닫기**(기본 켜짐): 사이드바가 열려 있으면 페이지가 그만큼 좁아져 좁게 찍힌다. 닫고, **페이지가 넓어질 때까지 기다렸다가**(최대 1.3초) 찍는다. 캡처가 끝나면 그 탭의 사이드바를 **다시 켜 두고** 결과를 **페이지 위 알림**으로 알린다(다시 열면 캡처 쪽에 같은 글이 보인다). **여는 것은 확장이 못 한다** — Chrome 이 `sidePanel.open()` 을 사용자가 누른 직후에만 허락한다. 확장 아이콘이나 도크 창의 ☰ 를 누르면 열린다.
- **고르기 창이 첫 번에 뜨게**(v0.32.0): 사이드바가 닫히며 초점이 움직이는 순간과 겹치면 Chrome 이 고르기 창을 닫아 버렸다. 사이드바를 먼저 닫고 450ms 뒤에 녹화 창을 연다(v0.33.0 에서 고르기 자체를 손길 방식으로 바꿨다).
- **도크 분리**: 도크의 ⧉ 단추를 누르면 **단추 줄만 담은** 작은 창이 뜬다(v0.33.0 에서 알림줄·자리 고르는 줄을 없앴다). 처음에는 화면 **위쪽 가운데**에 뜨고, 제목 표시줄을 끌어 원하는 자리에 두면 그 자리를 기억한다. 이 창의 **선택 영역 캡처는 화면 전체**에서 고른다 — 다른 앱도, 다른 모니터 위의 창도 찍힌다(발표 도우미 앱이 찍어 ‘캡처이미지’ 폴더에 저장하고 복사한다). 발표·핀·캡처를 사이드바 없이 쓸 수 있다. (보통 창이라 다른 앱을 누르면 뒤로 간다. 늘 맨 앞에 둬야 하면 앱 쪽으로 옮겨야 한다.)
- **맥에서 전체 화면·창이 흐릴 때**: Chrome 에 화면 기록 권한이 없는 것이다. 녹화 창이 그때 안내와 **시스템 설정 열기** 단추를 보여 준다(도우미 앱이 그 자리를 연다). 허용 뒤 Chrome 을 완전히 껐다 켜야 한다.

### 화면 조각 핀
- 화면의 한 부분을 끌어서 잘라 **늘 위에 뜨는 카드**로 붙여 둡니다. 페이지를 넘기거나 다른 앱으로 가도 카드는 그대로 남아, 앞 장과 견주며 설명할 때 씁니다. 클립보드의 그림이나 글도 그대로 붙일 수 있습니다(글은 쪽지 모양 카드가 됩니다).
- 여는 방법 세 가지: 사이드바 **발표 탭의 `화면 조각 잘라 붙이기`**, 앱 메뉴(macOS 메뉴 막대 → `화면 조각 핀`, Windows 트레이), 발표 중 단축키 `Control + Option/Alt + S`.
- 핀 하나를 다루는 방법: **끌어서 이동**, **휠** 크기, **Command/Ctrl + 휠** 투명도, **두 번 누르기** 접기, **오른쪽 클릭** 전체 메뉴(그리기 · 잘라내기 · 복사 · 바탕화면에 저장 · 회전 · 좌우 뒤집기 · 원래대로 · 클릭 통과), **Esc** 그 핀만 닫기. 키로도 됩니다 — `d` 그리기, `x` 잘라내기, `c` 복사, `s` 저장, `1`·`2` 회전, `3` 뒤집기, `0` 원래대로, `t` 클릭 통과, `Space` 접기.
- **조각 위에 그리기:** 붙인 핀에 바로 표시할 수 있습니다. 핀에 마우스를 올리면 뜨는 **✎** 단추(또는 `d` 키, 오른쪽 클릭 메뉴)를 누르면 핀 아래에 도구 줄이 나타납니다.
  - 도구 다섯 가지: **펜**(자유롭게 긋기) · **원**(둘러싸기) · **밑줄**(곧은 선) · **모자이크**(가리기) · **글자**(눌러서 자리를 정하고 타자, Return으로 끝)
  - **색** 6가지(빨강·노랑·초록·파랑·검정·흰색), **굵기와 글자 크기**는 `· • ●` 3단계를 한 손잡이로 함께 고릅니다.
  - `↶`로 하나씩 되돌리고, 그 **바로 옆 `✓ 마침`** 단추로 끝냅니다(`Return`·`Esc`도 같습니다). `⌫`는 그린 것을 모두 지우되 그리기에서 나가지는 않습니다.
  - **나가는 길은 모두 그린 것을 남깁니다** — `✓` · Return · Esc 어느 쪽이든 그린 것이 그림 자체에 들어갑니다. 그 뒤에는 복사·바탕화면 저장·다시 자르기·회전·이동에 **그대로 따라옵니다.**
  - **그리는 도중에도 핀을 옮길 수 있습니다** — macOS는 `Command`, Windows는 `Ctrl`을 누른 채 끌면 그린 그대로 따라옵니다.
  - 고른 색은 **칸 자체가 그 색으로 남고 흰 테두리**가 생깁니다.
  - 키로도 됩니다 — `p` 펜, `o` 원, `l` 밑줄, `m` 모자이크, `t` 글자, `z` 되돌리기.
- **모퉁이로 다시 자르기:** 붙인 뒤에 더 좁힐 수 있습니다. 핀에 마우스를 올리면 뜨는 **⛶** 단추(또는 `x` 키, 오른쪽 클릭 메뉴)를 누르면 네 모퉁이에 손잡이와 삼등분 선이 생깁니다. **모퉁이를 끌어** 남길 부분을 정하고 **Return**(Windows는 Enter)으로 자릅니다. 안쪽을 끌면 선택한 영역을 통째로 옮기고, 바깥을 끌면 새로 잡습니다. **Esc는 자르기만 취소**하고 핀은 닫지 않습니다. 자른 결과가 그 핀의 새 원본이 되므로 이어서 또 자를 수 있고, 잘린 만큼 픽셀을 그대로 보존합니다.
- **클릭 통과**는 핀을 "유리처럼" 만드는 기능입니다. 켜면 그 핀은 눌러도 반응하지 않고 **클릭이 아래 화면으로 통과**합니다. 참고 그림을 띄워 두고 그 자리의 버튼을 그대로 눌러야 할 때 씁니다. 켜는 법: 핀에서 `t` 키 또는 오른쪽 클릭 → `클릭 통과`. 켜진 핀은 **테두리가 주황색**으로 바뀝니다.
- **통과 중에도 투명도는 휠로 바로 바꿉니다**(v0.33.0): 통과를 켜면 그 핀은 마우스를 받지 못하므로, 발표 도우미 앱이 그 핀 위에서만 휠을 가로채 **불투명도**를 올리고 내립니다(아래 화면은 함께 스크롤되지 않습니다). 맥에서는 앱에 손쉬운 사용 권한이 있어야 합니다.
- **켜고 끄는 길이 양쪽에 다 있습니다.** 사이드바 발표 탭의 `핀 클릭 통과` 스위치, 도크의 `◌` 단추, 앱 메뉴의 `클릭 통과 켜기 · 끄기`, `Control + Option/Alt + T` — 어느 것이든 **붙여 둔 핀 전체를 한 번에** 켜고 끕니다. 몇 개가 통과 중인지 사이드바에 숫자로 나옵니다.
- **클릭 통과 해제**는 그 반대입니다. 통과를 켠 핀은 눌리지 않으니 그 핀에서는 끌 수 없습니다. 그래서 바깥에서 되돌리는 길을 셋 뒀습니다 — 사이드바 발표 탭의 `클릭 통과 해제` 버튼, 앱 메뉴(macOS 메뉴 막대 → 화면 조각 핀 → 클릭 통과 모두 해제 · Windows 트레이), `Control + Option/Alt + T`. 누르면 **통과를 켠 핀이 전부 다시 눌리게** 됩니다. 핀이 없거나 통과를 켠 핀이 없으면 아무 일도 하지 않습니다.
- 한 번에 12개까지 띄울 수 있습니다. 저장하면 바탕화면에 `다있쌤-핀-…png`로 남습니다. 복사한 뒤 메모의 자동 가져오기가 켜져 있으면 메모에도 들어갑니다.
- **확대·집중 모드와 섞이지 않습니다.**
  - macOS: 핀은 화면 캡처에서 제외되고 확대 화면보다 위에 뜹니다. 4배로 키우거나 바깥을 흐리게 해도 핀은 **원래 크기 그대로 또렷하게** 남습니다.
  - Windows: 확대 API가 바탕화면 전체를 키우므로, 큰 포인터와 같은 방식으로 핀을 배율만큼 줄여 그려 **화면에 보이는 크기와 자리를 일정하게** 유지합니다. 다만 OS가 화면을 키우는 것이라 확대 중에는 핀도 함께 흐려집니다.
  - 조각을 자르는 동안에만 확대가 잠시 원래 크기로 돌아갔다가 되돌아옵니다(눈에 보이는 자리와 실제 화면 좌표가 어긋나지 않게 하기 위해서입니다).
  - `Esc`는 핀을 고른 상태면 그 핀만, 조각을 자르는 중이면 자르기만 취소합니다. 그 밖에는 기존대로 확대 해제 → 발표 종료입니다.
- **단축키는 앱이 켜져 있으면 늘 듣습니다.** 발표 중이 아니어도 됩니다(`RegisterEventHotKey` 로 등록하므로 손쉬운 사용 권한도 필요 없습니다). 앱이 꺼져 있으면 듣지 않습니다.

## 사용

**확장을 지울 때의 로그아웃은 없습니다.** v0.28.0 에서 뺐습니다. Chrome 은 확장이 제거되면 지정된 주소를 여는 것 말고는 아무 것도 허용하지 않는데, 그 주소로 Google 로그아웃 페이지를 열어도 **실제로 계정이 로그아웃되지 않습니다**(Google 로그아웃은 단순 주소 열기로 되지 않습니다). 되지도 않는 것을 설정에 남겨 두면 지켜 주는 줄 알고 믿게 되므로 지웠습니다. 다른 사람에게 컴퓨터를 넘길 때는 아래 **프로필 잠금**을 쓰세요.

**게스트 창으로 넘기기:** 잠금 화면(기존 페이지 안내와 새 탐색 화면 모두)에 `게스트 창으로 넘어가기` 버튼이 있습니다. 다른 사람이 실수로 들어왔을 때 한 번 누르면 **게스트 프로필 창**이 열려 내 프로필을 건드리지 않고 그 사람이 쓸 수 있습니다. 발표 도우미 앱이 설치돼 있으면 진짜 게스트 창을, 없으면 시크릿 창을 엽니다.

**프로필 잠금:** 컴퓨터를 넘기기 전에 ‘잠그기’를 누릅니다. 기존 HTTP(S) 페이지에 PIN 확인 안내를 표시하고 클릭·입력을 막습니다. 잠긴 상태에서 북마크를 열거나 주소를 입력해 새로 이동하면 확장 잠금 화면으로 넘어갑니다. 기존 페이지 안내와 같은 녹색 화면이며 ‘PIN 확인하기’로 해제하면 원래 주소로 돌아갑니다. 단축키는 Windows `Ctrl+Shift+L`, Mac `Command+Shift+L`입니다(다른 확장과 충돌하면 Chrome 확장 단축키 설정에서 변경). **시작 잠금(기본 켜짐):** 프로필 설정의 `브라우저를 다시 시작하거나 화면이 잠기면 자동으로 잠그기`를 켜 두면, 컴퓨터를 켜고 Chrome을 열었을 때 **항상 잠긴 상태로 시작**합니다. 절전이나 화면 잠금에서 깨어날 때도 잠깁니다. 끄면 다시 열어도 풀린 상태가 유지됩니다(권장하지 않음). 여기에 더해 선택적인 1/5/15/30분 유휴 잠금을 지원합니다.

**빠른 메모:** 메모 아래 네 버튼은 각각 이렇습니다.
- **지금 저장** — 메모는 타자마다 자동 저장됩니다. 이 버튼은 기다리지 않고 바로 동기화를 밀어 넣습니다.
- **글 복사** — 지금 보고 있는 메모의 글을 클립보드에 담습니다. 다른 앱에서 Ctrl+V(Mac은 Command+V). 캡처 이미지는 목록의 각 줄에 있는 ‘복사’를 씁니다.
- **인쇄** — 새 탭을 열어 제목·본문 전체·가져온 캡처를 한 장으로 인쇄합니다. 사이드 패널에서는 인쇄 창을 띄울 수 없어 탭을 엽니다.
- **파일로 ↗** — 이 메모를 텍스트 파일로 내려받습니다.
 메모를 여러 개 만들 수 있습니다. 위쪽 **탭을 한 번 눌러 바로 전환**하고, 탭이 많아지면 옆으로 넘겨 봅니다. `+`로 추가, 제목 칸에서 이름 변경, ‘삭제’로 지웁니다. 이름을 비워 두면 `9/18 15:35`처럼 **날짜와 시각이 자동으로 들어갑니다**. 삭제는 다른 기기에도 전달됩니다. ‘복사’를 누르면 현재 메모가 클립보드에 담겨 다른 앱에서 Ctrl+V(Mac은 Command+V)로 붙여 넣을 수 있습니다. 입력을 로컬에 먼저 보관하고 Chrome Sync로 전달합니다. ‘저장’을 누르면 즉시 동기화 저장을 시도합니다. 다른 컴퓨터에 도착하는 시각은 보장하지 않습니다. 충돌을 피하려고 기기별 최신 사본을 유지하며 ‘다른 기기 사본’에서 선택할 수 있습니다. 편집 중인 내용이 다른 사본 선택으로 바뀌는 경우 기존 내용을 텍스트 파일로 내보냅니다.

**메모 고정(핀):** 제목 옆 📌를 누르면 그 메모가 **편집 칸 위에 고정**됩니다. 여러 개를 고정하면 아래로 쌓이며 **모두 보이는 상태로 남습니다.** 제목을 누르면 그 메모로 이동하고, `고정 해제`로 내립니다.

**빠른 조작 도크:** 탭 줄 **위에** 늘 떠 있습니다. 어느 탭을 보고 있든 스크롤 없이 발표 시작·종료, 집중 모드, 화면 조각, 핀 닫기, 캡처 둘, 도크 분리, 프로필 설정, 잠금에 바로 닿습니다(단추 11개가 한 줄). ‘클립보드 붙이기’ 는 자리가 모자라 도크에서 뺐습니다 — 발표 탭과 따로 띄운 도크 창, 단축키로 씁니다. 단추에 마우스를 올리면 아래 줄에 이름과 단축키가 뜹니다.

**Command + 휠로 화면 크기 조절 (macOS):** macOS에는 없는 기능입니다. Command를 누른 채 휠을 굴리면 Command + `+`/`−` 와 **똑같은 단계로** 페이지가 커지고 작아집니다. Chrome 기본 배율 단계를 그대로 쓰므로 Command + `0` 으로 원래대로 돌아갑니다. 프로필 설정에서 끌 수 있고, Windows는 Ctrl + 휠이 이미 같은 일을 합니다.

**유틸리티 탭:** 수업에 쓰는 도구를 한 곳에 모았습니다. 각 칸은 삼각형을 눌러 접고 펼칩니다.
- **스톱워치** — 시작/멈춤, 구간 기록. **사이드바를 닫아도 계속 흐르고** 다시 열면 이어집니다.
- **타이머** — 분·초를 정하면 **사이드바를 닫아도** 알림과 소리로 알려 줍니다.
- **수업 시보** — 시각을 여러 개 등록하면 매일 그 시각에 종이 울립니다. **시보 전용 소리와 볼륨**을 따로 정하며 두 번 울립니다.
- **타이머 알림음** — 타이머용 소리와 볼륨을 따로 정하고 미리 들어 봅니다. 소리는 5종입니다.
- **팀 포인트 판** — 팀 수(1~12)를 정하고 팀 이름과 점수를 적습니다. `+` `−`로 1점씩 올리고 내리거나 숫자를 직접 입력합니다. `점수 0으로`, `이름까지 초기화`가 있습니다.
- **발표자 뽑기** — 번호 범위를 정해 굴림 애니메이션으로 뽑습니다. 이미 뽑힌 번호 제외를 켤 수 있습니다.
- **소음 측정기** — 마이크로 소리 크기만 막대로 보여 줍니다. **녹음하지 않고 어디로도 보내지 않습니다.**
- **유튜브 뮤직 조종기** — 별도 탭에서 연 유튜브 뮤직의 재생·정지·이전·다음과 검색을 조종합니다. 이 확장이 음악을 재생하거나 저장하지 않습니다.
- **녹음기** — 사이드바 안에서 바로 녹음합니다. 소리 크기가 파형으로 흐르고, 가운데 빨간 단추로 시작·종료, 양옆에서 잠시 멈춤과 끝내기를 합니다. **끝내면 바로 들어 볼 수 있고, `저장`을 눌러야 파일로 내려받습니다**(마음에 안 들면 `지우기`). **마이크**와 **시스템·탭 소리**를 녹음합니다. 둘을 **한 파일로 합쳐** 저장하거나 **소리마다 따로** 저장할 수 있고, 합칠 때는 소리별 크기를 조절합니다. 막대로 입력 크기를 보여 주고 잠시 멈춤도 됩니다. 별도 창이라 사이드바를 닫아도 계속 녹음합니다.
  - 시스템 소리는 공유 창에서 **‘소리 공유’를 켜야** 들어옵니다. **Windows**는 화면 전체를 고르면 컴퓨터 소리 전체가, 탭을 고르면 그 탭 소리만 녹음됩니다. **macOS는 Chrome이 탭 소리만** 내주므로 화면 전체 소리는 녹음되지 않습니다(Chrome의 제약입니다).
  - Chrome이 소리만 공유하는 것을 허용하지 않아 화면 트랙을 함께 받아 두고 쓰지 않습니다. 그래서 녹음 중에는 **‘화면 공유 중’ 표시**가 뜹니다. 저장 파일에는 소리만 들어갑니다.
  - 파일은 `.webm`(Opus)으로 **이 컴퓨터에 내려받기만** 합니다. 어디로도 보내지 않고 확장 안에도 남기지 않습니다.
  - **녹음 중에는 사이드바를 닫지 마세요.** 닫으면 녹음이 끝납니다(닫히는 순간까지의 소리는 저장을 시도합니다). 한 시간이 넘는 녹음은 `별도 창에서 녹음 ↗`으로 여세요 — 그 창은 사이드바와 무관하게 살아 있습니다.
- **웹캠** — 별도 창에서 미리보기·녹화·사진 저장. 결과물은 **이 컴퓨터에 파일로만** 내려받습니다.

**북마크:** 프로필 잠금만 풀면 바로 보입니다. **별도 PIN을 더 묻지 않습니다.** **‘지금 보는 페이지 추가 +’**를 누르면 현재 탭의 제목과 주소가 한 번에 들어갑니다(Chrome 내부 화면은 주소를 읽을 수 없어 저장되지 않습니다). 주소를 직접 입력해 넣을 수도 있습니다.
- **폴더:** 위쪽 `폴더 +`로 만들고 탭을 눌러 그 폴더만 봅니다. 각 줄의 선택 상자로 폴더를 옮기고, 폴더를 지우면 안에 있던 링크는 지워지지 않고 ‘폴더 없음’으로 옮겨집니다.
- **암호화하지 않습니다.** v0.4까지의 PIN 보관함과 달리 제목과 주소가 그대로 Chrome 동기화에 올라갑니다. 비밀번호나 일회용 토큰이 들어간 주소는 저장하지 마세요.
- 이전에 PIN으로 잠갔던 중요 북마크가 있으면 북마크 화면 아래에 **옮기기 안내**가 뜹니다. 그 PIN을 한 번 넣으면 목록으로 옮기고 이전 보관함을 지웁니다.
- 백업 내보내기/가져오기는 평문 JSON입니다.

**전체 백업 · 복원 (v0.39.0):** 설정 페이지의 ‘전체 백업 · 복원’이 메모·북마크·설정·수업 도구(그리고 암호를 건 백업이면 잠금 PIN)를 **파일 하나**로 저장하고, 다른 컴퓨터나 **다른 Google 계정**의 Chrome에서 불러옵니다. 처음 쓰는 컴퓨터는 PIN 만드는 첫 화면의 ‘백업에서 복원’으로 시작할 수 있습니다. 규칙: ① 잠금 PIN은 **암호를 건 백업에만** 담습니다(PBKDF2-SHA256 60만 회 + AES-256-GCM, 암호는 저장하지 않으며 잊으면 열 수 없음). ② 복원은 **더하기만** 하며 지금 있는 메모·북마크를 지우거나 덮어쓰지 않습니다(내용이 다른 같은 메모는 ‘(백업)’ 사본). ③ 이미 PIN이 있는 컴퓨터에서 PIN을 바꾸는 복원은 현재 PIN을 먼저 확인합니다. ④ 기기 번호·도크 자리·카메라/마이크 번호는 담지 않습니다. 바탕화면 ‘캡처이미지’ 폴더의 그림 파일은 확장이 읽을 수 없어 담지 못하고(썸네일만) 직접 복사해야 합니다.

## 데이터와 제한

- Chrome Sync는 Google의 동기화 서버를 이용합니다. 자체 운영 서버가 없다는 의미이며 기기끼리 직접 전송하는 방식은 아닙니다. 실제 지연 측정 기능/테스트는 포함하지 않습니다.
- 메모·암호화 북마크 전체는 약 100KB, 한 항목은 약 8KB 제한을 공유합니다. 여유 공간을 두고 검사합니다. 메모 하나는 5,500 UTF-8 바이트까지 동기화합니다. 메모를 여러 개 두면 전체 100KB 한도를 함께 씁니다. 이를 넘는 메모는 로컬에 보존하고 오류를 표시하므로 파일로 내보내세요. 매우 큰 입력은 200,000자에서 거부됩니다.
- 북마크는 기기별 암호화 스냅샷을 합칩니다. 삭제 표시도 남겨 오프라인 기기에서 삭제한 링크가 되살아나는 것을 방지합니다. 저장 공간이 가득 차면 새 변경을 거부하며 기존 저장 내용을 자르지 않습니다.
- 북마크 PIN 분실 복구와 PIN 변경은 현재 버전에서 제공하지 않습니다. PIN을 안전하게 기억하고 암호화 백업을 보관하세요. 프로필 PIN 분실 시 재설치 전 메모·북마크를 접근 가능한 기기에서 백업해야 합니다. 확장 삭제는 데이터 삭제로 이어질 수 있습니다.
- 잠금은 우발적인 사용 방지용입니다. Chrome 내부 화면·북마크 바·주소창·PDF 뷰어·확장 비활성화는 보호하지 않으며 잠금 적용 전 순간 노출이 있을 수 있습니다. 저장된 비밀번호나 기존 Chrome 북마크를 수정하지 않습니다.
- 별도 북마크를 추가해도 일반 Chrome 북마크에 남아 있던 원본은 사라지지 않습니다. 사이트를 연 후의 탭·방문기록은 숨기지 않습니다. 짧은 PIN은 오프라인 추측 공격까지 막는 강한 보안 금고가 아닙니다.

## 개발과 검증

Node.js 24, Swift 6.4 CLI(macOS 빌드), .NET SDK 8(Windows 교차 빌드)를 사용했습니다. 확장은 외부 라이브러리 없이 실행됩니다.

```sh
npm test
npm run check
bash presenter/macos/build.sh
dotnet publish presenter/windows/Presenter.csproj -c Release -o dist/windows
npm run package
```

`node scripts/preview.mjs`는 `http://127.0.0.1:4178/extension/panel.html`에서 실제 패널 코드와 **가짜 Chrome API**를 연결하는 UI 검사 전용 서버입니다. 배포 ZIP에는 테스트 도구가 들어가지 않습니다. `tests/guard-preview.html`은 기존 페이지를 보존하는 잠금 화면 검사입니다.

자동 테스트는 암호화·잘못된 PIN·한글 바이트 제한·기기별 병합·삭제·초과 메모 보존·실패 재시도·동시 창 쓰기 충돌·잠금 메시지 순서를 검사합니다. 브라우저 UI 검증은 테스트 API 환경에서 수행했습니다. 실제 Chrome 확장 로드, 계정 간 동기화, 양 OS의 화면 확대·화면 공유 수신 측 동작은 별도 실기기 검증 항목입니다. Windows EXE와 Mac 공용 앱은 빌드됐지만 이를 실기기 검증 통과로 간주하지 않습니다.

검증 기록과 남은 작업: `docs/ai/HANDOFF.md`, `docs/ai/VALIDATION.md`.
